# 学习流程

1. **先搞懂题目在算什么。** 只学向量点积、矩阵形状、转置和下标。能用纸笔算出一个 `M=2、N=3、K=2` 的例子，并说清楚为什么是“每行先取最大值，再把各行相加”。

2. **用普通 C++ 写一个慢但正确的版本。** 练习多层循环、一维数组表示矩阵、下标计算和边界处理。尤其检查负数输入、最后不足一整块的数据，以及不同转置情况。这一步不需要昇腾环境；工作区也有[仅用 CPU 的检查说明](D:/CANN/test1/tests/README.md:19)。它能帮你核对计算逻辑，但不能证明设备代码正确。

3. **再学 Ascend C 的最小必需部分。** 按工作区这份[中文入门教程](D:/CANN/cann-learning-hub/tutorials/ascendc_operator_development_light/README.md:43)读：**1.3、1.4 → 2.3、2.5 → 3.2、3.3、3.5**。重点弄明白全局内存、片上内存、分块、核间分工，以及矩阵乘结果怎样交给向量计算。官方[编程范式说明](https://www.hiascend.com/document/detail/zh/canncommercial/83RC1/opdevg/Ascendcopdevg/atlas_ascendc_10_00033.html)也有中文解释。

4. **最后读组内通过版。** 从[入口函数](D:/CANN/answer/experimental/kernel_team_passed.asc:359)看输入和形状，再看[分块方案](D:/CANN/answer/experimental/kernel_team_passed.asc:40)、[主体计算](D:/CANN/answer/experimental/kernel_team_passed.asc:189)、[行最大值合并](D:/CANN/answer/experimental/kernel_team_passed.asc:73)。每读一段，只回答三个问题：**谁负责这块数据？数据放在哪里？边界不足一块时怎么办？**
